# ✖️ Multiplication Table Quiz

A completely free, browser-based application built to help students practice multiplication tables through customizable, interactive quizzes. The app requires no backend server and stores all progress locally, ensuring data privacy and instant loading.

## ✨ Key Features
* **Three Exam Modes:** Practice via Multiple Choice, Typed Answers, or Reverse (finding factor pairs).
* **Customizable Difficulty:** Adjust complexity levels (Easy, Medium, Hard), specific table ranges (e.g., 2-9), and the number of questions.
* **Instant Analytics:** View detailed post-quiz results, including average time per question and accuracy percentages.
* **Long-term Tracking:** Built-in leaderboard, history logs, and trend charts to monitor a student's progress over time.
* **Exportable Data:** Download quiz results locally as a CSV or JSON file for teachers or parents to review.
* **Responsive Design:** Optimized for both desktop browsers and mobile touch screens.

## 🚀 Usage & Hosting
This project is a single static HTML file (`index.html`). It is currently hosted via GitHub Pages and is fully functional out of the box without any build tools or databases.
